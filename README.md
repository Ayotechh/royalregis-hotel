# Royal Regis Hotel & Resorts — Website Concept

A responsive React + TypeScript + Tailwind CSS concept homepage created by Ayotech Solutions for a management discussion. Uses Lucide React icons.

## Run locally

Requirements: Node.js 20+.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite.

## Production build

```bash
npm run build
npm run preview
```

## Important concept notes

- This is a visual concept, not the hotel's approved production website.
- Photography is illustrative stock imagery loaded from Unsplash; replace it with approved Royal Regis photographs before launch.
- Room types, amenities, rates, availability, operating hours, phone numbers and email should be confirmed by hotel management.
- The enquiry form is intentionally demo-only. It does not transmit or save personal information. Connect it to an approved email, WhatsApp, CRM or booking provider only after approval.
- No real booking engine, payment flow, backend or analytics is configured.
- The site uses Tailwind CSS v3, Vite, React, TypeScript and Lucide React.
